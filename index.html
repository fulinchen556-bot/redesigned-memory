CASE 01 · INTERNSHIP PROJECT

简化宠物问诊，
降低就医门槛。

面向 18-25 岁、养宠 1-3 年的年轻宠主，把自由文本输入改为结构化病情模板，让医疗信息既严谨，也更容易表达。

角色
UI/UX 设计实习生
周期
约 3 个月
方法
访谈 / 问卷 / 信息架构 / 可用性测试

01 / 问题

新手知道宠物不舒服，却不知道怎么讲清楚。

自由文本需要用户主动组织医疗信息，容易遗漏医生关心的重点。就医流程和分级提示也不够清楚，进一步增加焦虑。

02 / 决策

用结构降低表达门槛，同时保留专业信息。

  • 按宠物类型、症状、持续时间组织关键问题。
  • 将复杂判断转化为渐进式选择，而不是一次填满表单。
  • 在信息完整性与操作效率之间建立清楚层级。

03 / 结果

从研究到验证，完整走完一次体验迭代。

测试用户填写信息所需时间缩短，用户反馈更容易说清宠物症状。这个项目也让我确认：设计要优先服务真实诉求。

项目平台基础数据 - 500+ 持证兽医、100+ 合作医院、20 万+ 宠主反馈、5 万+ 线上问诊，均非本次改版带来的新增成果。

CASE 02 · CONCEPT REDESIGN

适老化金融，
看懂银行服务。

以普通中青年用户与老年用户为目标，通过调研、信息架构和交互验证，探索更清楚、更易理解的银行服务体验。

状态
概念改版 · 未上线
调研
32 份问卷 + 8 位高龄用户访谈
重点
适老化 / 通俗化 / 流程可视化

01 / 挑战

信息更多，还是更容易理解？

产品希望保留更多内容，但高龄用户面对密集信息容易失去判断。我制作两组原型进行对照测试，用反馈支撑精简方案。

02 / 方案

让首屏只回答最重要的三个问题。

高频信息与主要操作优先展示，详细说明允许展开。更大的点击区域、清楚的反馈和流程状态，共同降低使用压力。

03 / 结果

测试反馈支持分层折叠，也改变了我的判断方式。

项目验证了适老化、金融信息通俗化与流程可视化的方向。我也学会用用户反馈处理分歧，而不是只依赖个人审美。

概念改版，用于体验设计探索与方案验证，未正式上线。

CASE 03 · SELF-INITIATED

亲民餐饮品牌，
建立快乐的视觉语言。

围绕“健康、传统、福气”建立早餐品牌视觉，从 Logo、色彩与字体，到原创 IP、包装、周边及多媒介应用。

性质
自主品牌练习 · 无真实门店落地
角色
独立完成
范围
Logo / VI / IP / 插画 / 包装

01 / 建立识别

让包子不只是一种食物，也成为有情绪的角色。

用蓝、白、橙建立清爽温暖的色彩关系，再把品牌内核转化为容易亲近的原创 IP“包宝儿”。

02 / 延展

一套视觉，要在不同媒介里仍然像同一个品牌。

将 IP、插画与色彩规范延展到包装、海报、门店、外卖平台和周边，训练统一视觉系统在不同场景下的适配能力。

03 / 复盘

一个 IP 不是一张可爱插画，而是一套可延展的识别系统。

这个项目让我把绘画、插画和品牌规范放进同一套视觉逻辑中，也提升了造型、色彩与画面层级的控制力。

自主品牌练习，无真实门店落地，不包含客户销售或传播数据。
